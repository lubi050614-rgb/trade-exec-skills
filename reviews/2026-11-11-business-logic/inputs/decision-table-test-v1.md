版本：v1.0｜事实核验基准：2026-11-11（Asia/Shanghai）｜测试策略：test-v1

本文件交付一张有来源、施行日期、默认动作及适用边界的决策表，以及五类可手算的逐事件账户案例。它用于补齐交易执行工具的业务规范与验收依据，不是单因子统计检验模块的指标说明。

## 1. 核验结论与适用范围

**事实、接口语义和原创系统约定分开标注。** 已核验的规则有官方正文或发布公告支持；案例中的价格、资金、费用、合约乘数及保证金率是人工测试数据，未冒充真实行情、券商费率或某个合约的当前参数。

- A股核心案例使用沪深普通主板现金账户、普通限价单。决策表额外列出科创板的数量差异。北交所、ETF、B股、融资融券、期权、港股通不自动继承该profile。
- CTA案例是线性、人民币计价、无组合保证金优惠的虚拟商品期货账户。上期所制度用于核对保证金及日终结算原则；虚拟合约不能在实盘路由。其他期货交易所及各品种参数需独立绑定。
- “已核验”表示核对了本次选定官方版本及相关条款。不能由此推导所有品种、临时公告和账户合同已被穷尽核查。本文件不是全市场实盘上线认证。
- `T0`统一指2026-11-11，仅是test-v1测试约定起算日。原创策略的实盘生效日为“未启用”，并非用户已授权实盘执行。

## 2. 决策与账本的共同定义

### 2.1 决策动作

| 动作 | 精确定义 |
| --- | --- |
| ALLOW | 通过本地检查并原子预留后允许发送；不代表柜台/交易所受理，更不代表成交 |
| REJECT | 拒绝本次请求；如尚未发送，不新增冻结；已有订单不因此被撤销 |
| WAIT | 等待前置条件或回报；原订单及必要冻结继续存在 |
| CANCEL_REQUEST | 发送撤单申请；只有收到有效确认且明细对齐后才能释放相应余量冻结 |
| RECONCILE | 查询委托、成交、持仓、资金并核对；暂停相关新增风险，继续处理事实事件 |

`CANCELED_PARTIAL`等是内部规范化状态，不是冒充某个柜台的原始枚举。保留`raw_status`、来源和映射版本。`cancel_pending`应独立保存，避免丢失原单的部分成交状态。

### 2.2 字段和资金口径

| 字段 | 本文件含义 |
| --- | --- |
| A股现金余额C | 内部交易账本的现金额，扣除已入账成交款及费用；不是银行可取资金，也不是法律交收完成证明 |
| 订单预留F | 尚未成交/尚未核清部分需要保留的本金或费用；内部冻结模型需与柜台映射 |
| A股可用A | 本简化模型中A=C−F；实盘柜台还可能有其他调整项 |
| 总持仓Q / 可卖Qs | Q包含今日新买；Qs仅为本profile允许卖出且未被其他卖单占用的部分 |
| 期货账面余额B | 已确认的结算余额加结算后已实现盈亏、出入金及费用等 |
| 期货未实现盈亏U | 从前结算基准/当日开仓基准至指定mark的剩余持仓盈亏 |
| 期货动态权益E | 本模型E=B+U；不能把保证金再次当成损失扣减E |
| 持仓保证金M | 本测试模型为abs(持仓手数)×指定估值价×乘数×保证金率 |
| 冻结保证金Fm / 冻结费用Ff | 活动订单尚未消耗、仍需预留的保证金和预计费用 |
| 期货可用A | 本模型A=E−M−Fm−Ff；正可用不等于必然满足所有柜台开仓限制 |

冻结既可能反映为柜台字段，也可能为本地预留；适配时不得把同一笔资源扣减两次。真实账户优先核对柜台字段、报告和客户合同。盘中保证金估值价、浮盈可用比例及多空保证金优惠等不具有跨柜台统一公式，本文件只固定测试模型。

### 2.3 规则求值顺序

对“新请求”：产品及规则版本 → 交易阶段和权限 → 数量价格 → 资源与风险 → 原子预留 → 发送。遇到硬性失败则拒绝；数据未知则等待/对账；只有检查全部通过才发送。不得因为某一条ALLOW就覆盖其他失败条件。

对“已发生的回报”：先验证事件身份、去重和一致性，再记账。即使策略停止、行情过期或连接刚恢复，也必须处理已经发生的有效成交。成交事实和风险指令冲突时，不可为了使风控指标好看而丢弃成交。

## 4. 五类逐事件验收案例

以下都是人工合成的确定性事件回放，不声称真实市场一定按该顺序或价格成交。日期和时刻用于事件顺序；D1=2026-11-11、D2=2026-11-12仅作为测试交易日标签，不据此声称某个真实合约在该日挂牌、开放交易或采用这些参数。

每个案例独立初始化；活动订单、未说明费用、出入金、其他持仓、公司行为均为零。数值用十进制定点计算，人民币保留到分；本批测试数字不产生舍入争议。`order_id`、成交号与合约代码都是虚构标识。
